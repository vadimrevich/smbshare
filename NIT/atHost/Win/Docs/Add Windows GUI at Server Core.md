# Add Windows GUI at Server Core

**Чтобы загрузить графический интерфейс (GUI) в Microsoft Windows Server Core, можно воспользоваться следующими методами**:

1. **Запуск Explorer++**. В Windows Server Core изначально отсутствует проводник Explorer, поэтому первым шагом нужно загрузить Explorer++. Для этого необходимо загрузить на локальную рабочую станцию дистрибутив браузера, подключиться к серверу и создать там директорию для обмена файлами. Затем нужно распаковать загруженный архив, скопировать файл Explorer++.exe в общую папку на сервере и запустить приложение из командной строки. [2](https://ultravds.com/blog/ucnfyjdrf-gui-na-windows-server-core/)
2. **Установка родного браузера**. Этот метод предполагает использование дополнительного пакета компонентов Server Core App Compatibility Feature on Demand (FOD). Он может вернуть в систему средство «Просмотр событий», монитор ресурсов, проводник и даже Windows PowerShell. Для установки пакета нужно войти в PowerShell и запустить команду:

    ```powershell
    Add-WindowsCapability -Online -Name ServerCore.AppCompatibility~~~~0.0.1.0
    ```

    . После этого необходимо перезапустить сервер:

    ```powershell
    Restart-Computer
    ```

    . [2](https://ultravds.com/blog/ucnfyjdrf-gui-na-windows-server-core/)

Также можно использовать **консоль Server Manager**. Для этого нужно подключиться к серверу с GUI и открыть консоль Server Manager. Затем нажать на «Управление» и в выпадающем меню выбрать «Добавить роли и функции». После этого выбрать свой сервер Core в списке и нажать «Далее». Далее на странице «Выбор функций» прокрутить вниз до раздела «Пользовательские интерфейсы и инфраструктура», развернуть выбор, выбрать «Графические инструменты и инфраструктура» и «Графическая оболочка сервера» и нажать «Далее». На странице «Подтверждение выбора установки» нажать «Указать альтернативный путь источника». На странице «Указать альтернативный путь источника» ввести путь к установочному носителю, затем нажать «ОК». На странице «Подтверждение выбора установки» выбрать чекбокс «При необходимости автоматически перезагрузить сервер назначения» и нажать «Установить». После этого сервер перезагрузится с полным GUI. [3](https://garvis.ca/2013/12/24/step-by-step-adding-the-gui-to-windows-server-core/)[4](https://winitpro.ru/index.php/2013/03/22/windows-server-2012-pereklyuchenie-mezhdu-rezhimami-gui-i-core/)

Если не удаётся самостоятельно установить GUI, рекомендуется обратиться к специалисту.
