# Update Windows 10+

В статье расказывается, как обновить операцонную систему Windows 10+ (сереверные и клиентские версии) после установки.

## Введение

Сразу после установки операционной системы Microsoft Windows, даже до её активации, необходимо произвести её обновление. Обновление установит необходимые драйверы и обновит стек безопасности.

## Перед проведением обновлений

Перед началом обновления вам, возможно, потребуется установка драйверов сетевой карты (если она у вас не опозналась автоматически при установке Microsoft Windows). Зайдите на официальный сай производителя Вашего компьютера и загрузите файлы драйверов для Вашей операционной системы. Распакуйте эти драйверы, если они заархивированы у вас в архивы, и скопируйте в каталог загрузочного флеш-диска.

**Примечание**. Загрузку драйверов лучше производить до установки операционной системы. Обязательно загружайте драйверы с сайта производителя, даже если они там не самые новые. Производитель часто «допиливает» драйверы вендора, устанавливает свои сертификаты, без которых работоспособность драйверов и устройств не гарантироуется.

**Примечание**. Особенно следует остановиться на установке неподдерживаемых операционных систем. Вариант с откатом к устаревшим системам даже не рассматривается — в этом случае не гарантируется работа даже с базовыми функциями. Речь идёт, например, о серверных операционных системах, устанавливаемых на рабочие станции. Как правило, здесь тоже возможны проблемы с совместимостью оборудования. Универсального решения здесь нет. Вполне вероятно, подойдут драйверы более старых моделей того же производителя. Но здесь нужно произвести полноценный OSINT.

## Загрузка обновлений

1. Перейдите на сайт: <http://win.netip4.ru/win10plusupdate/>
2. Следуйте инструкциям по первоначальной настройке даты и времени, клавиатуры, имени компьютера и окружения.
3. Загрузите на компьютер ISO образы с обновлениями.

## Установка Windows Store

Для установки магазина приложений *Windows Store* и менеджера пакетов *winget* на неподдерживаемое оборудование необходимо: 1) подключить загруженый диск `WindowsStore.iso`, 2) Запустить в нём файл: `autorun.exe`, 3) Следовать инструкциям по установке в `*.chm` файле.

Как правило, после указанных процедур у вас в системе появятся приложения Microsoft Store и WunGet. На некоторых старых версиях ядра Windows 10 (например, на версиях Windows Server 2019 и старше, а также на версиях Windows без рабочего стола) магазин Windows может не установиться из-за неподдерживаемого прогнраммного обеспечения.

## Установка базовых обновлений Windows

Для установки базовых оббновлений Microsoft Windows необходимо:
1) подключить диск `NIT-SomePSGUI.iso`, 2) запустить файл `autorun.exe`, 3) Открыть онлайн-справку на диске, 4) согласно справке последовательно запускать п установочные пакеты 1-5, 5) после установки каждого пакета перезапускать Microsoft Windows.

После установки базовых обновлений компьютер будет работать значительно быстрее, а вы сможете безболезненно и без помощи специалистов устанавливать другое программное обеспечение и игры.

Более того, на компьютер установятся программы удалённой поддержки и мониторинга New Internet Technologies, Inc. Вы всегда сможете получить помощь от профессионалов рынка.
