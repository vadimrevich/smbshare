# Приложение ru.netip4.win.netcondition_001.txt

Данное приложение запускает таймер только в том случае, если установлено сетевое соединение с сервером и определённый файл доступен для скачивания.

## Алгоритм

При вызове метода onResume() вызывается функция toCheckNetConnections(). Эта функция проверят возможность установления соединения с сервером. Если соединение возможно установить, запускаются таймеры, внутри которых выполняется функции toGetAFileTimer_xxx_xx. Эти функции проверяют существование файлов на сервере, и запускает какое-то действие в случае их присутствия (например, меняет цвет одного из дочерних лайоутов). Сама функция toCheckNetConnections() повторно вызывается после отработки самого долгого таймера. На экране должна присутствовать кнопка, аварийно завершающее приложение. Также выполнение проверок завершается после потери приложением Android фокуса ввода.
