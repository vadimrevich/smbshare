# KAV Antivirus Exckusions

## в каком файле антивирус касперского хранит исключения антивируса

Возможно, имелся в виду файл **kav-server\_exclusions.xml**, который, по информации из документации Kaspersky Security Server 10, содержит список исключений для антивируса. [docs.librasoft.by](https://docs.librasoft.by/Kaspersky_Security_Server_10_exclusions.pdf)

В продуктах Kaspersky настройки исключений находятся в разделе «Угрозы и исключения». [infars.ru](https://infars.ru/blog/kak-dobavit-fayl-programmu-ili-sayt-v-isklyucheniya-kaspersky/)[](https://blog.kaspersky.kz/how-to-add-apps-to-exclusions/24356/)
