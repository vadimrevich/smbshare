**В Linux есть программы, которые позволяют просматривать файлы разных форматов**: документы (PDF, EPUB и др.), изображения, видео и аудио. ## Для документов (PDF, EPUB и др.)

-   **Okular** — универсальный просмотрщик документов, разработанный KDE. Поддерживает форматы PDF, EPUB, DjVU и другие. Некоторые функции:
    -   аннотации, выделение текста; [datanumen.com](https://www.datanumen.com/ru/%D0%B1%D0%BB%D0%BE%D0%B3%D0%B8/11-%D0%BB%D1%83%D1%87%D1%88%D0%B8%D0%B9-pdf-viewer-tools-in-linux-free/)
    -   создание закладок; [datanumen.com](https://www.datanumen.com/ru/%D0%B1%D0%BB%D0%BE%D0%B3%D0%B8/11-%D0%BB%D1%83%D1%87%D1%88%D0%B8%D0%B9-pdf-viewer-tools-in-linux-free/)
    -   просмотр миниатюр страниц; [pingvinus.ru](https://pingvinus.ru/program/okular)
    -   поиск по документу; [pingvinus.ru](https://pingvinus.ru/program/okular)
    -   поворот страниц. [pingvinus.ru](https://pingvinus.ru/program/okular)
-   **Evince** — универсальный просмотрщик документов, поддерживает форматы PDF, XPS, DVI, TIFF, DJVU и другие. Позволяет поворачивать страницы и менять их размер, отображать оглавление, если оно присутствует в оригинальной разметке файла. [pdf-editor.su](https://pdf-editor.su/programma-dlya-prosmotra-pdf-linux.php)
-   **Atril** — стандартный просмотрщик документов в графической среде MATE, но может использоваться и на других платформах. Поддерживает опцию поиска, закладки и вращение листов, есть режим презентации, в котором листы выводятся на экран целиком. [pdf-editor.su](https://pdf-editor.su/programma-dlya-prosmotra-pdf-linux.php)

## Для изображений

-   **Nomacs** — бесплатное приложение для просмотра изображений с открытым исходным кодом. Поддерживает работу с большинством популярных форматов изображений, есть настройки: цвет, яркость, изменение размера, обрезка.
-   **Eye of GNOME** — классический просмотрщик изображений, разработанный в рамках проекта GNOME. Позволяет организовывать библиотеки изображений, есть функция слайд-шоу для представления изображений по порядку.
-   **Eye of MATE** — просмотрщик изображений с базовыми возможностями, адаптированный под работу в рабочем окружении MATE. Поддерживает множество популярных форматов изображений.
-   **gThumb Image Viewer** — универсальная программа для просмотра и управления изображениями, есть инструменты для манипулирования изображениями (обрезка, изменение размера, корректировка цветов).

## Для видео

-   **VLC** — медиаплеер с открытым исходным кодом, поддерживает различные форматы видеофайлов. Можно настроить внешний вид с помощью скинов, расширять функциональные возможности с помощью расширений.
-   **GNOME Videos** (Totem) — медиаплеер, используется как приложение по умолчанию для рабочей среды GNOME. Поддерживает множество форматов аудио и видео, включая MP4, AVI, MKV и OGG. С его помощью можно скачивать и настраивать субтитры к видеофайлам и загружать метаданные и обложки к роликам.
-   **SMPlayer** — свободный, открытый и кросс-платформенный мультимедийный проигрыватель, основан на MPlayer. Позволяет изменять внешний вид с помощью скинов и настраивать параметры субтитров: размер, цвет, фон и задержку.

## Для аудио

-   **Rhythmbox** — аудиоплеер, воспроизводит и помогает организовать цифровую музыку. Поддерживает различные форматы, есть функции: воспроизведение без пробелов, поддержка Last.fm (позволяет воспроизводить потоковую музыку в интернете).
-   **Qmmp** — кроссплатформенный аудиоплеер на базе Qt, поддерживает широкий спектр аудиоформатов, включая FLAC, Ogg Vorbis, MPEG-1 и AAC.
-   **Amberol** — музыкальный плеер, разработанный для среды рабочего стола GNOME, поддерживает различные аудиоформаты и предлагает чистый интерфейс для управления списками воспроизведения.
-   **Kew** — музыкальный плеер командной строки, позволяет слушать музыку прямо в терминале. Поддерживает различные аудиоформаты, включая MP3, FLAC и OGG, и обладает такими возможностями, как создание плейлистов, воспроизведение без пробелов и поиск в библиотеке по частичным названиям.
