# KEENETIC-CLI Боковое перемещение

Итак, допустим, что вы получили доступ к  админке роутера Netcraze в интерфейсе командной строки. Перечислим дальнейшие действия по компрометации системы.

## 1\. Проверка интерфейсов

Вначале нужно подать команду:

```bash
(config)> show interface | grep name
```

Этой командой Вы можете просмотреть активные интерфейсы на роутере. Нас больше всего интересуют интерфейсы `PPPoE0`, `Home`. Первый интерфейс служит для подсоединения домашней сети к Интернету. Второй интерфейс — домашняя сеть тестируемого. Проверяем:

```bash
(config)> show interface PPPoE0
```
```bash
(config)> show interface Home
```

Как правило, эти команды дадут исчерпывающую информацию о соединении.

## 2\. Проверки DHCP

Далее, на домашнем интерфейсе, можно проверить назначение постоянного соответствия IP  и MAC адресов.

```bash
(config)> show ip dhcp pool | grep -C 1 Home
```

```bash
(config)> show ip dhcp bindings _WEBADMIN
```

```bash
(config)> show ip dhcp bindings _WEBADMIN | grep -C 1 infinity
```

После вызова последней команды мы сможем увидеть все закреплённые за физическими и виртуальными устройствами IP и MAC адреса в домашней сети, а также возможные их mDNS имена.

## 3\. Проверка arp таблицы

Теперь можно подавать команду:

```bash
(config)> show ip arp
```

Как вы можете видеть по предыдущему выводу, в этой таблице много меньше реальных устройств. Причём могут даже отсутствовать те устройства, которые есть в сети, но находятся в «спящем режиме». Для их прорбуждения необходимо подать команду:

```bash
(config)> tools arping {ip address} source-interface Home count 4
```
где `{ip address}` — IP адрес устройства из команды *show ip dhcp bindings*. Необходимо пройти по всем адресам из списка:

```bash
(config)> show ip dhcp bindings _WEBADMIN | grep -C 1 infinity | grep ip
```

После опять можно вызвать программу *show ip arp*.

Таким образом мы можем определить все присутствующие в системе устройства. Далее можно закреплить/откреплять другие устройства и пробрасывать порты.

## 4\. Проверка наличия флешки Entware

Необходимо подать команды:

```bash
(config)> show usb | grep -C 1 media
```

В случае положительного ответа мы определим, что в системе присутствует USB флешка.

```bash
(config)> show media | grep -C 2 OPKG
```

В случае положительного ответа мы определим, что в системе присутствует флешка с разделом *OPKG*, и, возможно, в системе установлена Entware.

Далее нужно подать команду:

```bash
(config)> exec sh
```

И мы окажемся в оболочке *ash* Keenetic c привилегиями пользователя root. Можно установить дополнительные пакеты Entware и использовать роутер как дочку доступа к ресурсам сети.

## 5\. Дополнительные действия

### 5\.1\. Проброс из-за NAT

Как известно, в 21 веке найти домашний роутер, имеющий белый IP — почти призрачная удача. Поэтому стоит просмотреть вопрос организации на роутере обратного прокси, прежде всего для портов SSH. Об обратных прокси авторы уже писали.

Следует отметить, что обратные прокси будут работать только в системе Entware, поэтому не забудьте проверить доступ из раздела 4\.
