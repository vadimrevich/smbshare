# Send files from cmd

Как оправить файлы по E-mail из командной строки

- Установите CygWin.
- Через программу cygwinsetup установите smtp client msmtp, e-mail client mutt и, опционально, tmux.
- Скопируйте настройки с сервера автора в файле ~/.msmtprc и в каталоге ~/.mutt
- Измените владельца этих файлов.
- Установите стандартные расширения для файлов в каталоге ~/.mutt и права 0600 на файл ~/.msmtprc
- Можете оправлять файлы следующими командами:

```bash
cat ./msg.txt | msmtp -a default you@example.com
````
- Данныая команда отравляет текст письма из файла `./msg.txt` из профиля msmtp *default* по адресу *yuu@example.com*. Письмо отправляется без темы и вложений, поле from указывается жёстко в профиле.

```bash
cat ./msg.txt | mutt -s "My Subject" you@example.com -a ./attachment
```
- Данная команда отпраляет текст письма из файла `./msg.txt` по адресу *you@example.com* с темой `My Subject` и вложением `./attachment`. Поле From и настройки сервера задаются жёстко в файле  `~/.mutt/muttrc`.
- **Внимание!!!** Установка и расположение файлов настроек в роутерах (например, Keenetic) отличается от установки в CygWin, Linux. Смотри справку в Интернете.
- *Примечанеие*. Если надо запустить файлы cygwin из окна Windows, необходимо в командных файлах Windows:
- Врекменно добавить путь CygWin `C:\tools\cygwin\bin` в переменную *Path*.
- Запускать программы скриптов из командной строки как обычно, а bash скрипты — через `bash.exe`.
