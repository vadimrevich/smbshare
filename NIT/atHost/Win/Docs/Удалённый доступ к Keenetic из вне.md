**Удалённый доступ к интерфейсу командной строки (CLI) интернет-центра Keenetic из командной строки возможен через сервер SSH (Secure Shell — безопасная оболочка)**. Это доступно начиная с версии операционной системы ОС 2.12. [support.keenetic.ru](https://support.keenetic.ru/start/kn-1111/ru/22340-ssh-remote-access-to-the-keenetic-command-line.html)[help.keenetic.com](https://help.keenetic.com/hc/ru/articles/360003153619-%D0%94%D0%BE%D1%81%D1%82%D1%83%D0%BF-%D0%B8%D0%B7-%D0%98%D0%BD%D1%82%D0%B5%D1%80%D0%BD%D0%B5%D1%82%D0%B0-%D0%BA-%D0%B8%D0%BD%D1%82%D0%B5%D1%80%D1%84%D0%B5%D0%B9%D1%81%D1%83-%D0%BA%D0%BE%D0%BC%D0%B0%D0%BD%D0%B4%D0%BD%D0%BE%D0%B9-%D1%81%D1%82%D1%80%D0%BE%D0%BA%D0%B8)

**Важно**: по умолчанию доступ к управлению интернет-центром из внешней сети (из Интернета) заблокирован. Это реализовано для безопасности устройства и локальной сети от несанкционированного доступа из внешней сети. [help.keenetic.com](https://help.keenetic.com/hc/ru/articles/213965629-%D0%9D%D0%B0%D1%81%D1%82%D1%80%D0%BE%D0%B9%D0%BA%D0%B0-%D1%83%D0%B4%D0%B0%D0%BB%D0%B5%D0%BD%D0%BD%D0%BE%D0%B3%D0%BE-%D0%B4%D0%BE%D1%81%D1%82%D1%83%D0%BF%D0%B0-%D0%BA-%D0%B8%D0%BD%D1%82%D0%B5%D1%80%D0%BD%D0%B5%D1%82-%D1%86%D0%B5%D0%BD%D1%82%D1%80%D1%83-%D0%B8%D0%B7-%D0%98%D0%BD%D1%82%D0%B5%D1%80%D0%BD%D0%B5%D1%82%D0%B0-%D0%B4%D0%BB%D1%8F-%D0%B2%D0%B5%D1%80%D1%81%D0%B8%D0%B9-NDMS-2-11-%D0%B8-%D0%B1%D0%BE%D0%BB%D0%B5%D0%B5-%D1%80%D0%B0%D0%BD%D0%BD%D0%B8%D1%85)[help.keenetic.com](https://help.keenetic.com/hc/ru/articles/360003153619-%D0%94%D0%BE%D1%81%D1%82%D1%83%D0%BF-%D0%B8%D0%B7-%D0%98%D0%BD%D1%82%D0%B5%D1%80%D0%BD%D0%B5%D1%82%D0%B0-%D0%BA-%D0%B8%D0%BD%D1%82%D0%B5%D1%80%D1%84%D0%B5%D0%B9%D1%81%D1%83-%D0%BA%D0%BE%D0%BC%D0%B0%D0%BD%D0%B4%D0%BD%D0%BE%D0%B9-%D1%81%D1%82%D1%80%D0%BE%D0%BA%D0%B8)

## Пошаговая инструкция

-   **Предварительно установить компонент системы «Сервер SSH»** в интернет-центре. Это можно сделать на странице «Общие настройки системы» в разделе «Обновления и компоненты», нажав на «Изменить набор компонентов».
-   **После установки компонента** сервер SSH будет включён автоматически, доступ к нему разрешён в локальных интерфейсах с уровнем безопасности private.
-   **Чтобы разрешить доступ из внешних сетей**, нужно серверу SSH установить **публичный уровень безопасности** в интерфейсе командной строки интернет-центра. Для этого нужно выполнить команды:
    -   ```
        (config)> ip ssh
        ```
        
        ;
    -   ```
        (config-ssh)> security-level public
        ```
        
        .
-   **Рекомендуется сменить стандартный порт сервера** — по умолчанию стандартный — с номером 22. Его можно поменять на один из неиспользуемых номеров (например, на 2022). Для этого нужно выполнить команду:
    
    ```
    (config-ssh)> port 2022
    ```
    
    .
-   **Для сохранения настройки** нужно выполнить команду:
    
    ```
    (config)> system configuration save
    ```
    
    .

**После настройки** пользователи, имеющие право доступа к командной строке Keenetic, смогут обратиться из SSH-клиента на внешний IP-адрес интернет-центра по порту, по которому работает сервер, и получить доступ к его командной строке в безопасном подключении. [support.keenetic.ru](https://support.keenetic.ru/start/kn-1111/ru/22340-ssh-remote-access-to-the-keenetic-command-line.html)

## Меры безопасности

-   **Доступ к интерфейсу командной строки Keenetic по протоколу SSH из Интернета возможен только при наличии публичного IP-адреса** на внешнем (WAN) интерфейсе, через который осуществляется подключение. Если интернет-центр для доступа в Интернет использует адрес из диапазона «серых» IP-адресов, подключение из Интернета к роутеру по протоколу SSH будет невозможно.
-   **Если ключи скомпрометированы**, сервер SSH может сгенерировать новые. Эта процедура происходит автоматически при установке компонента системы, но может также быть запущена по команде
    
    ```
    ip ssh keygen {keygen}
    ```
    
    , где вместо {keygen} следует указать нужный алгоритм.
    
**Файл /etc/hosts не редактируется на роутерах Keenetic**. Однако в интернет-центрах Keenetic есть возможность **настроить сопоставление доменного имени и IP-адреса** с помощью команды **ip host** в интерфейсе командной строки (CLI) роутера. [help.keenetic.com](https://help.keenetic.com/hc/ru/articles/360011129420-%D0%9E%D0%B1%D1%80%D0%B0%D1%89%D0%B5%D0%BD%D0%B8%D0%B5-%D0%BA-%D1%81%D0%B5%D1%82%D0%B5%D0%B2%D0%BE%D0%BC%D1%83-%D1%83%D1%81%D1%82%D1%80%D0%BE%D0%B9%D1%81%D1%82%D0%B2%D1%83-%D0%BF%D0%BE-hostname)[forum.keenetic.ru](https://forum.keenetic.ru/topic/14559-%D0%B0%D0%BD%D0%B0%D0%BB%D0%BE%D0%B3-etchosts-%D0%B2-keenetic-giga/)

Файл hosts — это системный файл, который позволяет вручную сопоставить доменные имена с IP-адресами. Он часто используется для блокировки сайтов, перенаправления адресов или тестирования веб-приложений до обновления DNS. [crypto-vps.com](https://crypto-vps.com/blog/redaktirovanie-fajla-etc-host/)

## Пошаговая инструкция

Чтобы настроить сопоставление доменного имени и IP-адреса в Keenetic, нужно: [help.keenetic.com](https://help.keenetic.com/hc/ru/articles/360011129420-%D0%9E%D0%B1%D1%80%D0%B0%D1%89%D0%B5%D0%BD%D0%B8%D0%B5-%D0%BA-%D1%81%D0%B5%D1%82%D0%B5%D0%B2%D0%BE%D0%BC%D1%83-%D1%83%D1%81%D1%82%D1%80%D0%BE%D0%B9%D1%81%D1%82%D0%B2%D1%83-%D0%BF%D0%BE-hostname)

1.  **Зарегистрировать на интернет-центре и присвоить постоянный IP-адрес необходимому хосту**. Регистрацию можно выполнить в веб-конфигураторе на странице «Список клиентов».
2.  **Подключиться к CLI интернет-центра** и выполнить команды:
    -   ```
        ip host <доменное_имя_хоста> <адрес>
        ```
        
        . Доменное имя хоста рекомендуется указать в формате доменных имён 2-го уровня в виде localhost.localdomain (например: my.comp, test.local, host.test, pc.example).
    -   ```
        system configuration save
        ```
        
        .
