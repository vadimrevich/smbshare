**Настроить локаль (язык) в Kali Linux можно через графический интерфейс или терминал**. Выбор способа зависит от того, какой интерфейс используется (GNOME, XFCE и т. д.) и какую часть системы нужно русифицировать. [dzen.ru](https://dzen.ru/a/aBYXVJ2Aqy7hIENc)

## Через графический интерфейс

**Чтобы изменить язык интерфейса** (GNOME, XFCE и другие DE), нужно: [dzen.ru](https://dzen.ru/a/aBYXVJ2Aqy7hIENc)

1.  Открыть «Settings» («Параметры»). В зависимости от окружения рабочего стола значок «Settings» может выглядеть по-разному, обычно он находится в меню приложений.
2.  Найти раздел «Region & Language» («Регион и язык») или «Language & Region» («Язык и регион»). Название может немного отличаться в зависимости от версии Kali Linux и используемого окружения рабочего стола.
3.  В разделе «Language» («Язык») выбрать «Русский» (Russian). Если русского языка нет в списке, нажать кнопку «+» или «Add Language» («Добавить язык») и найти «Русский» в списке доступных языков.
4.  Установить русский язык в качестве основного, переместить его на первое место в списке языков.
5.  Применить изменения. Возможно, потребуется перезагрузить систему, чтобы изменения вступили в силу.

 [dzen.ru](https://dzen.ru/a/aBYXVJ2Aqy7hIENc)

В некоторых случаях после выбора языка будет предложено установить языковой пакет (language pack), нужно подтвердить установку. [dzen.ru](https://dzen.ru/a/aBYXVJ2Aqy7hIENc)

## Через терминал

**Если нет графического интерфейса или для автоматизации**, можно настроить локаль через терминал: [dzen.ru](https://dzen.ru/a/aBYXVJ2Aqy7hIENc)

1.  **Установить русские локали**:
    -   ```
        sudo apt update
        ```
        
        ;
    -   ```
        sudo apt install locales
        ```
        
        ;
    -   ```
        sudo dpkg-reconfigure locales
        ```
        
        .
2.  **В открывшемся окне выбрать ru\_RU.UTF-8** (и, возможно, ru\_RU.KOI8-R для совместимости со старыми программами) с помощью клавиш управления курсором и пробела.
3.  **Нажать Enter**.
4.  **Выбрать ru\_RU.UTF-8** в качестве языка системы по умолчанию.
5.  **Установить языковые пакеты**:
    -   (для GNOME) —
        
        ```
        sudo apt install gnome-language-selector gnome-language-selector
        ```
        
        ;
    -   (для XFCE) —
        
        ```
        sudo apt install system-config-language sudo system-config-language
        ```
        
        .
6.  **Настроить переменные окружения**:
    -   Открыть файл ~/.profile (или ~/.bashrc) в текстовом редакторе:
        
        ```
        nano ~/.profile
        ```
        
        .
    -   Добавить следующие строки в конец файла:
        
        ```
        export LANG="ru_RU.UTF-8" export LANGUAGE="ru_RU.UTF-8" export LC_ALL="ru_RU.UTF-8"
        ```
        
        .
    -   Сохранить файл и закрыть редактор.
    -   Применить изменения:
        
        ```
        source ~/.profile
        ```
        
        .
    -   Перезагрузить систему:
        
        ```
        sudo reboot
        ```
        
        .

 [dzen.ru](https://dzen.ru/a/aBYXVJ2Aqy7hIENc)

**Важно**: перед внесением изменений рекомендуется создать резервную копию важных файлов. Если используется нестандартное окружение рабочего стола, инструкции могут отличаться. После выполнения всех действий рекомендуется перезагрузить систему.
