# Install ub64 Guest at Oracle VirtualBox

- Проверьте, что файл `ub64.ova` полностью загружен в папку *Загрузки* текущего пользователя.
- Запустите файл `VBoxManage_import_ub64.bat` для импорта виртуальной машины в рабочее окружение VirtualBox.
- Для проброса портов с гостевой машины, расположенной за NAT, в локальную сеть используйте файл: `VBoxManage_modvn_netnat_ub64_set.bat`. Для отмены такого проброса используйте файл: `VBoxManage_modvn_netnat_ub64_unset.bat`.
- Установленная виртуальная машина удаляется только вручную, из графической оболочки VirtualBox.
- Для управления виртуальной машиной из командной строки смотрите остальные файлы и документацию к VirtualBox.

### Подключение к сети типа "мост"

Виртуальная машина Oracle VirtualBox позволяет подключаться к внешней локальной сети не только через NAT, но и напрямую, используя соединение типа мост. 

- Чтобы определить, какие сети могут быть соединены с виртуальной машиной мостом, запустите файл: `..\VBoxManage_list_brifs.bat`. Далее можно найти нужный интерфейс по ip либо mac адресу.
- Чтобы подключиться к сети как мост, необходимо запустить скрипт: `VBoxManage_modvn_netbridged.bat` при выключенноной гостевой виртуальной машине.
- Чтобы вернуться обратно в сеть NAT, необходимо запустить: `VBoxManage_modvn_netnat.bat`.

## Приложения

### Приложение 1. Учётные записи

Для входа на виртуальную машину используйте следующие учётные записи:

- root:0A9s8d7F
- user:0A9s8d7F
- MSSQLSR:Admin01234

### Приложение 2. Проброшенные порты в режиме NAT.

На хост машину `127.0.0.1` в данной гостевой машины проброшены следующие порты:

- 22 -> 15022
- 23 -> 15023
- 10000 -> 15000

Для разблокировки брандмауэра, пожалуйста, запустите скрипт `..\VBox.advFirewall.bat`. Помните, по умолчанию проброс портов не работает, он включается только скриптами выше.
