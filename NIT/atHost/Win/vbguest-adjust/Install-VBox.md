# Install-VBox

Установка виртуальной машины VirtualBox на компьютер с операционной системой Microsoft Windows 10+ в командной строке.

## Введение

Для целей пентестинга были созданы гостевые виртуальные машины, работающие под управлением последних версий Oracle VirtualBox в операционых системах Microsoft Windows 10+. Для их работы в систему необходимо установить указанную виртуальную машину на хост компьютер. Именно это решают Command Shell скрипты в данной папке.

## Системные требования к хост-машине

- Минимум четырехядерный Intel совместимый процессор.
- Оперативная память > 4 Гбайт (желательно от 8 Гбайт).
- Операционная система Microsoft Windows 10+ (желательна 11+)
- 50 Гбайт свободного места на диске C.
- Установленные менеджеры пакетов Chocolatey и/или WinGet.

Для установки менеджеров пакетов можно воспользоваться предлагаемыми скриптами PowerShell (в папке `..\PackageManagers-Install`).

## Порядок установки виртуальной машины

- Убедитесь, что в вышей системе установлены менеджеры пакетов Chocolatey/WinGet. Без них запуск скриптов завершится с ошибкой.
- Запустите скрипт:

```
.\VBox_install_viaChocolatey.bat
```
или 

```
.\VBox_install_viaWinGet.bat
```

в командной строке Windows в зависимости от того, какой менеджер пакетов у вас установлен (один из двух).

- Для настройки установки запустите, пожалуйста, следующие скрипты:

```
.\VBoxCreateBaseFolder.bat
.\VBox_install_with_extension.bat
```

## Удаление VirtualBox

Для удаления Oracle VirtualBox через менеджер пакетов запустите, пожалуйста, следующие команды от имени администратора:

```
choco uninstall -y VirtualBox
winget uninstall oracle.virtualbox
```
